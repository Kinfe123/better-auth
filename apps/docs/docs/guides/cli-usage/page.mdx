## Command Mental Model
- `prepare` runs `lefthook install --reset-hooks-path` and supports the project workflow.
- `build` runs `turbo build --filter=./packages/*` and creates the production build or compiled package artifacts.
- `dev` runs `turbo dev --filter=./packages/* --filter=!./packages/cli` and starts the local development workflow.
- `clean` runs `turbo clean --filter=./packages/* && rm -rf node_modules` and removes generated artifacts so the next build starts from a clean state.
- `format` runs `biome format . --write` and checks or fixes code style before changes are shipped.
- `format:md` runs `pnpm --filter docs format:md` and checks or fixes code style before changes are shipped.
- `format:check` runs `pnpm --filter docs format:check` and checks or fixes code style before changes are shipped.
- `lint` runs `biome check . --error-on-warnings` and checks or fixes code style before changes are shipped.
- `lint:dependencies` runs `knip && knip --production` and checks or fixes code style before changes are shipped.
- `lint:fix` runs `biome check . --fix --unsafe` and checks or fixes code style before changes are shipped.
- `lint:spell` runs `cspell . --color` and checks or fixes code style before changes are shipped.
- `lint:types` runs `turbo lint:types --filter=./packages/*` and checks or fixes code style before changes are shipped.
- `lint:packages` runs `turbo lint:package --filter=./packages/*` and checks or fixes code style before changes are shipped.
- `changeset` runs `changeset` and supports the project workflow.
- `ci:version` runs `changeset version && pnpm install --no-frozen-lockfile` and supports the project workflow.
- `ci:release` runs `turbo clean --filter=./packages/* && turbo build --filter=./packages/* && changeset publish` and prepares or publishes package releases.
