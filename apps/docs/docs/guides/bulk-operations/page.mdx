# Bulk Operations

The product includes bulk creation, seeding, import, or export operations.
## What This Is
Bulk operations help operators or developers create, update, export, or seed many records at once. This page explains safety boundaries because bulk actions can change a lot of data quickly.
## Why It Matters
Bulk Operations matters because it is part of how Root turns repository behavior into a usable developer or operator workflow. This page gives readers the mental model first, then uses implementation evidence as supporting context.
## Core Concepts
- bulk actions
- seed data
- import
- export
- test records
## Typical Workflow
1. Choose the target record type and operation.
2. Review generated or imported records before committing changes.
3. Use bulk actions primarily for controlled admin tasks, demos, testing, or migrations.
