# Start Command

The CLI exposes a start command and runtime flags.
## What This Is
The start command launches the standalone runtime. This page explains what it serves, which project files it discovers, and how flags change host, port, browser opening, config path, watch mode, or other runtime behavior.
## Why It Matters
Start Command matters because it is part of how Root turns repository behavior into a usable developer or operator workflow. This page gives readers the mental model first, then uses implementation evidence as supporting context.
## Core Concepts
- CLI start
- standalone server
- runtime flags
- config discovery
## Typical Workflow
1. Run the command from the host project root.
2. Let the command auto-detect configuration or pass an explicit config path.
3. Open the served URL and verify it can reach the host runtime and database setup.
