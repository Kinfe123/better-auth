# Authentication

Better Auth supports email/password authentication out of the box and integrates with dozens of OAuth social providers. Every provider follows the same pattern: get credentials from the provider's developer portal, add them to your `betterAuth()` config under `socialProviders`, and call `authClient.signIn.social({ provider: "..." })` from the browser.

## Email & Password

Email and password authentication is built into the core. Enable it with one option:

```ts
export const auth = betterAuth({
  emailAndPassword: {
    enabled: true,
  },
})
```

Once enabled, you can call `authClient.signIn.email()` and `authClient.signUp.email()` from the client. The core also handles password changes, email verification, and password reset flows.

## OAuth Callback URL Pattern

Every provider uses the same callback URL shape:

```
https://your-domain.com/api/auth/callback/<provider-id>
```

For local development this is typically `http://localhost:3000/api/auth/callback/<provider-id>`. Register this exact URL in the provider's developer portal. If you change the `basePath` of your auth routes, update the callback URL to match.
