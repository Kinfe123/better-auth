# Paybin

This page explains how to configure Paybin OAuth in Better Auth.

## Get your credentials

1. Log in to your [Paybin Portfolio](https://portfolio.paybin.io).
2. Navigate to **Developer Settings** or **OAuth Applications**.
3. Click **Create OAuth Application** and fill in the details.
4. Set the redirect URI to `http://localhost:3000/api/auth/callback/paybin` for development.
5. Copy the **Client ID** and **Client Secret** to your environment variables.

## Configure the provider

```ts
import { betterAuth } from "better-auth";

export const auth = betterAuth({
  socialProviders: {
    paybin: {
      clientId: process.env.PAYBIN_CLIENT_ID as string,
      clientSecret: process.env.PAYBIN_CLIENT_SECRET as string,
    },
  },
});
```

## Custom scopes

By default the provider requests `openid`, `email`, and `profile`. You can extend this:

```ts
paybin: {
  clientId: process.env.PAYBIN_CLIENT_ID as string,
  clientSecret: process.env.PAYBIN_CLIENT_SECRET as string,
  scope: ["openid", "email", "profile", "transactions"],
},
```

For the full list of available scopes, see the [Paybin OIDC Scopes Documentation](https://developers.paybin.io/knowledge-center/oidc#available-scopes).

## Sign in

```ts
await authClient.signIn.social({ provider: "paybin" });
```
