# GitLab

This page explains how to configure GitLab OAuth in Better Auth.

## Get your credentials

Create an OAuth application in your GitLab account. Set the redirect URL to `http://localhost:3000/api/auth/callback/gitlab` for local development. See the [GitLab OAuth documentation](https://docs.gitlab.com/ee/api/oauth2.html) for steps.

## Configure the provider

```ts
import { betterAuth } from "better-auth";

export const auth = betterAuth({
  socialProviders: {
    gitlab: {
      clientId: process.env.GITLAB_CLIENT_ID as string,
      clientSecret: process.env.GITLAB_CLIENT_SECRET as string,
    },
  },
});
```

If you're using a self-hosted GitLab instance, you can pass the `issuer` option pointing to your GitLab domain.

## Sign in

```ts
await authClient.signIn.social({ provider: "gitlab" });
```
