# Apple

This page explains how to configure Sign in with Apple in Better Auth. Apple has stricter requirements than most providers — you need an active Apple Developer account, and the callback URL must use HTTPS with a valid certificate.

## Get your credentials

You need a **Client ID** (Service ID) and a **Client Secret** (a signed JWT you generate from a `.p8` key file). Follow these steps in the [Apple Developer Portal](https://developer.apple.com/account/resources/authkeys/list):

1. Under **Certificates, Identifiers & Profiles**, create an **App ID** with the "Sign In with Apple" capability enabled.
2. Create a **Service ID** and enable "Sign In with Apple". Set the return URL to `https://yourdomain.com/api/auth/callback/apple`.
3. Under **Keys**, create a new key with the "Sign In with Apple" capability. Download the `.p8` file — it's only available once. Note the **Key ID** and your **Team ID**.

> **Warning:** Apple Sign In does not support `localhost` or plain HTTP. You must use a domain with a valid HTTPS certificate even during development.

## Generate the client secret

Apple's client secret is a short-lived JWT you sign with your `.p8` key:

```ts
import { importPKCS8, SignJWT } from "jose";

async function generateAppleClientSecret(
  clientId: string,
  teamId: string,
  keyId: string,
  privateKey: string
) {
  const key = await importPKCS8(privateKey, "ES256");
  const now = Math.floor(Date.now() / 1000);
  return new SignJWT({})
    .setProtectedHeader({ alg: "ES256", kid: keyId })
    .setIssuer(teamId)
    .setSubject(clientId)
    .setAudience("https://appleid.apple.com")
    .setIssuedAt(now)
    .setExpirationTime(now + 180 * 24 * 60 * 60)
    .sign(key);
}
```

## Configure the provider

```ts
import { betterAuth } from "better-auth";

export const auth = betterAuth({
  trustedOrigins: ["https://appleid.apple.com"],
  socialProviders: {
    apple: {
      clientId: process.env.APPLE_CLIENT_ID as string,
      clientSecret: await generateAppleClientSecret(
        process.env.APPLE_CLIENT_ID!,
        process.env.APPLE_TEAM_ID!,
        process.env.APPLE_KEY_ID!,
        process.env.APPLE_PRIVATE_KEY!
      ),
    },
  },
});
```

You must add `https://appleid.apple.com` to `trustedOrigins` so Better Auth allows communication with Apple's servers.

## Sign in

```ts
await authClient.signIn.social({ provider: "apple" });
```
