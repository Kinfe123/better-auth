# Figma

This page covers setting up Figma OAuth in Better Auth.

## Get your credentials

1. Sign in to Figma and open the [Developer Apps page](https://www.figma.com/developers/apps).
2. Click **Create new app** and fill in the name and description.
3. Set the redirect URI to `https://yourdomain.com/api/auth/callback/figma`.
4. Copy your **Client ID** and **Client Secret**.

The default scope is `current_user:read`. For file access, you can request `file_content:read`. Refer to the Figma OAuth scopes documentation for the full list.

## Configure the provider

```ts
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  socialProviders: {
    figma: {
      clientId: process.env.FIGMA_CLIENT_ID as string,
      clientSecret: process.env.FIGMA_CLIENT_SECRET as string,
    },
  },
})
```

## Sign in

```ts
import { createAuthClient } from "better-auth/client"

const authClient = createAuthClient()
await authClient.signIn.social({ provider: "figma" })
```
