# Figma

This guide covers adding Figma OAuth sign-in to your Better Auth instance.

## Get your credentials

1. Sign in to Figma and open the [Developer Apps page](https://www.figma.com/developers/apps).
2. Click **Create new app** and fill in the details.
3. Set the redirect URI to `https://yourdomain.com/api/auth/callback/figma`. For local development use `http://localhost:3000/api/auth/callback/figma`.
4. Copy your **Client ID** and **Client Secret**.

The default scope is `current_user:read`. For additional scopes like `file_content:read`, refer to the [Figma OAuth scopes documentation](https://developers.figma.com/docs/rest-api/scopes).

## Configure the provider

```ts
// lib/auth.ts
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  socialProviders: {
    figma: {
      clientId: process.env.FIGMA_CLIENT_ID as string,
      clientSecret: process.env.FIGMA_CLIENT_SECRET as string,
    },
  },
})
```

## Sign in

```ts
await authClient.signIn.social({ provider: "figma" })
```
