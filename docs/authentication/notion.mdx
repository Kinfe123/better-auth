# Notion

This guide shows you how to add Notion OAuth sign-in to your Better Auth instance.

## Get your credentials

1. Open the [Notion Developers Portal](https://www.notion.so/my-integrations) and create a new integration.
2. Under **OAuth Domain & URIs**, set the redirect URL to `http://localhost:3000/api/auth/callback/notion` for local development.
3. Enable the **"Read user information including email addresses"** capability.
4. Copy your **OAuth client ID** and **OAuth client secret**.

For most use cases you'll want a **public integration** so users from different workspaces can sign in. Internal integrations are limited to your own workspace.

## Configure the provider

```ts
// lib/auth.ts
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  socialProviders: {
    notion: {
      clientId: process.env.NOTION_CLIENT_ID as string,
      clientSecret: process.env.NOTION_CLIENT_SECRET as string,
    },
  },
})
```

## Sign in

```ts
await authClient.signIn.social({ provider: "notion" })
```
