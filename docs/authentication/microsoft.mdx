# Microsoft

This page covers enabling sign-in with Microsoft Azure Entra ID (formerly Active Directory) in Better Auth.

## Get your credentials

1. Sign in to the [Azure Portal](https://portal.azure.com/) and open **Microsoft Entra ID**.
2. Under **App registrations**, create a new registration.
3. Add a redirect URI: `http://localhost:3000/api/auth/callback/microsoft` for local development.
4. Under **Certificates & secrets**, create a new client secret.
5. Note the **Application (client) ID**, **Directory (tenant) ID**, and the client secret value.

## Configure the provider

```ts
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  socialProviders: {
    microsoft: {
      clientId: process.env.MS_APP_ID as string,
      clientSecret: process.env.MS_CLIENT_SECRET as string,
      tenantId: process.env.MS_TENANT_ID, // omit for multi-tenant apps
    },
  },
})
```

## Sign in

```ts
import { createAuthClient } from "better-auth/client"

const authClient = createAuthClient()
await authClient.signIn.social({
  provider: "microsoft",
  callbackURL: "/dashboard",
})
```

## Large profile images

Microsoft returns profile images as base64-encoded strings, which can exceed HTTP header size limits. Use `mapProfileToUser` to upload the image to your own storage or strip it:

```ts
microsoft: {
  clientId: process.env.MS_APP_ID as string,
  clientSecret: process.env.MS_CLIENT_SECRET as string,
  mapProfileToUser: (profile) => ({
    image: null, // or upload and return a URL
  }),
}
```

> **Note:** Entra does not emit the `email` claim for managed users by default. Request it as an optional claim in your app registration, and use `profile.oid` as the stable identity anchor rather than email.
