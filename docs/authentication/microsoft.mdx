# Microsoft

Better Auth supports sign-in via Microsoft Azure Entra ID (formerly Active Directory), so your users can authenticate with their Microsoft accounts.

## Get your credentials

Register an application in the [Microsoft Entra ID portal](https://entra.microsoft.com/). Set the redirect URL to `http://localhost:3000/api/auth/callback/microsoft` for development. See the [Microsoft Entra ID quickstart](https://docs.microsoft.com/en-us/azure/active-directory/develop/quickstart-register-app) for detailed steps.

## Configure the provider

```ts
import { betterAuth } from "better-auth";

export const auth = betterAuth({
  socialProviders: {
    microsoft: {
      clientId: process.env.MS_APP_ID as string,
      clientSecret: process.env.MS_CLIENT_SECRET as string,
      tenantId: process.env.MS_TENANT_ID, // optional; defaults to "common"
    },
  },
});
```

The `tenantId` option restricts sign-in to a specific Azure AD tenant. Omit it (or use `"common"`) to allow any Microsoft account.

## Sign in

```ts
import { createAuthClient } from "better-auth/client";

const authClient = createAuthClient();

await authClient.signIn.social({
  provider: "microsoft",
  callbackURL: "/dashboard",
});
```
