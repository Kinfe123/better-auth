# Cognito

Better Auth supports Amazon Cognito as a social provider using the hosted UI OAuth2 flow. You need an active User Pool and App Client in your AWS account.

## Get your credentials

1. In the [Amazon Cognito Console](https://console.aws.amazon.com/cognito/), create a **User Pool**.
2. Under **App clients**, create a new App client and note the **Client ID** and **Client Secret**.
3. Go to **Domain** and set a Cognito Hosted UI domain, for example `your-app.auth.us-east-1.amazoncognito.com`.
4. In **App client settings**, enable the **Authorization code grant** flow and the `openid`, `profile`, and `email` scopes.
5. Add your callback URL: `http://localhost:3000/api/auth/callback/cognito` for local development.

> **Note:** The callback URL you set in Cognito must match exactly what Better Auth sends. If you change the `basePath` of your auth routes, update the Cognito callback URL accordingly.

## Configure the provider

```ts
// lib/auth.ts
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  socialProviders: {
    cognito: {
      clientId: process.env.COGNITO_CLIENT_ID as string,
      clientSecret: process.env.COGNITO_CLIENT_SECRET as string,
      issuer: "replace-me" as string, // e.g. https://cognito-idp.us-east-1.amazonaws.com/<user-pool-id>
    },
  },
})
```

## Available scopes

Cognito supports `openid`, `profile`, `email`, `phone`, and `aws.cognito.signin.user.admin`. You must enable each scope you request in your App Client settings in the Cognito Console.

## Sign in

```ts
await authClient.signIn.social({ provider: "cognito" })
```
