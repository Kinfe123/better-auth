# Discord

This page covers getting your Discord OAuth credentials and adding Discord sign-in to your app.

## Get your credentials

1. Open the [Discord Developer Portal](https://discord.com/developers/applications) and create or select an application.
2. Under **OAuth2 → General**, add a redirect URL: `http://localhost:3000/api/auth/callback/discord` for local development.
3. Copy the **Client ID** and **Client Secret** from the OAuth2 settings page.

> **Note:** Discord returns `email: null` for phone-only accounts. Plan accordingly if email is required.

## Configure the provider

```ts
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  socialProviders: {
    discord: {
      clientId: process.env.DISCORD_CLIENT_ID as string,
      clientSecret: process.env.DISCORD_CLIENT_SECRET as string,
    },
  },
})
```

## Sign in

```ts
import { createAuthClient } from "better-auth/client"

const authClient = createAuthClient()
await authClient.signIn.social({ provider: "discord" })
```

## Bot permissions (optional)

If you request the `bot` scope, you can pass a bitwise `permissions` value to control what the bot can do in a server:

```ts
discord: {
  clientId: process.env.DISCORD_CLIENT_ID as string,
  clientSecret: process.env.DISCORD_CLIENT_SECRET as string,
  permissions: 2048 | 16384, // Send Messages + Embed Links
}
```

The `permissions` parameter only takes effect when the `bot` scope is included.
