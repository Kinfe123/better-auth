# Facebook

This page explains how to configure Facebook OAuth in Better Auth.

## Get your credentials

Create an app in the [Facebook Developer Portal](https://developers.facebook.com/). Navigate to **App Settings > Basic** and note:

- **App ID** — this is your `clientId`
- **App Secret** — this is your `clientSecret`

Set the redirect URL to `http://localhost:3000/api/auth/callback/facebook` for development.

> **Warning:** Never expose the `clientSecret` in client-side code.

## Configure the provider

```ts
import { betterAuth } from "better-auth";

export const auth = betterAuth({
  socialProviders: {
    facebook: {
      clientId: process.env.FACEBOOK_CLIENT_ID as string,
      clientSecret: process.env.FACEBOOK_CLIENT_SECRET as string,
    },
  },
});
```

## Custom scopes and fields

By default, Better Auth requests `email` and `public_profile`. You can extend this:

```ts
facebook: {
  clientId: process.env.FACEBOOK_CLIENT_ID as string,
  clientSecret: process.env.FACEBOOK_CLIENT_SECRET as string,
  scopes: ["email", "public_profile", "user_friends"],
  fields: ["user_friends"],
},
```

## Sign in with an ID token

If you already have a Facebook ID token on the client (for example from a native iOS app), you can sign in directly without a redirect:

```ts
await authClient.signIn.social({
  provider: "facebook",
  idToken: {
    token: idToken, // for limited login (iOS)
  },
});
```
