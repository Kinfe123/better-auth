# Naver

This page explains how to configure Naver OAuth in Better Auth.

## Get your credentials

Create an application in [Naver Developers](https://developers.naver.com/) and set the redirect URL to `http://localhost:3000/api/auth/callback/naver` for local development.

## Configure the provider

```ts
import { betterAuth } from "better-auth";

export const auth = betterAuth({
  socialProviders: {
    naver: {
      clientId: process.env.NAVER_CLIENT_ID as string,
      clientSecret: process.env.NAVER_CLIENT_SECRET as string,
    },
  },
});
```

## Sign in

```ts
await authClient.signIn.social({ provider: "naver" });
```
