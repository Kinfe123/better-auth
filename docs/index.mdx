# Introduction

Better Auth is the most comprehensive authentication framework for TypeScript. It gives you email/password sign-in, dozens of OAuth providers, two-factor authentication, organizations, API keys, and much more — all wired together through a single `betterAuth()` call and a type-safe client.

Unlike thin wrappers around a single OAuth library, Better Auth handles the full authentication surface: session management, database persistence through pluggable adapters, server-side route handling for Next.js, SvelteKit, SolidStart, and TanStack Start, and a plugin system that lets you extend every part of the stack without forking.

If you're starting fresh, head to [Quickstart](/docs/quickstart) to get a working auth instance in minutes, or [Installation](/docs/installation) for the full setup walkthrough. Once you're up and running, the [Authentication](/docs/authentication) section covers every social provider, and [Plugins](/docs/plugins) covers advanced capabilities like two-factor auth, organizations, and OpenAPI introspection.
