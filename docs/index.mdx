# Introduction

Better Auth is a framework-agnostic authentication and authorization framework for TypeScript. It gives you a production-ready auth layer — email/password, social OAuth, 2FA, organizations, API keys, and more — without forcing you into a specific runtime or database. Whether you're building on Next.js, SvelteKit, SolidStart, or TanStack Start, Better Auth plugs in with minimal glue code.

The library ships a rich plugin system so you can add capabilities like two-factor authentication, multi-tenant organization management, magic links, phone number verification, JWT support, and an OIDC provider by wiring in a single function call. You get a typed server instance and a matching typed client — the same API shape works across every supported framework.

If you're setting up Better Auth for the first time, go to [Quickstart](/docs/quickstart) for the fastest path to a working auth flow, or [Installation](/docs/installation) for a complete setup walkthrough. Once you're up and running, the [Authentication](/docs/authentication) section covers every social provider, and [Plugins](/docs/plugins) covers the optional capabilities you can layer on top.
