# Introduction

Better Auth is a framework-agnostic authentication and authorization framework for TypeScript. It gives you a complete auth system out of the box — email/password, social providers, sessions, and more — without tying you to a specific runtime or framework. Whether you're on Next.js, SvelteKit, SolidStart, or TanStack Start, Better Auth drops in without friction.

The plugin system is what sets it apart. Features like two-factor authentication, organization management, magic links, JWT sessions, and anonymous sign-in are each a one-line addition to your config. You compose exactly the auth stack your application needs, and nothing you don't.

If you're starting fresh, jump to [Quickstart](/docs/quickstart) to see a working example in under five minutes. If you already know what you need, head to [Installation](/docs/installation) for the full setup walkthrough, then browse [Authentication](/docs/authentication) for provider-specific guides or [Plugins](/docs/plugins) to explore optional capabilities.
