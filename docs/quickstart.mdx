# Quickstart

By the end of this page you'll have email/password sign-up, sign-in, and session management working end-to-end. The example uses Next.js App Router, but the pattern is the same for every supported framework.

## 1. Install Better Auth

```bash
npm i better-auth
```

## 2. Set your environment variables

```bash
DATABASE_URL="postgresql://user:password@localhost:5432/mydb"
BETTER_AUTH_SECRET="a-random-secret-at-least-32-characters"
BETTER_AUTH_URL="http://localhost:3000"
```

`BETTER_AUTH_SECRET` is used to sign sessions. Generate one with `openssl rand -base64 32`.

## 3. Create the server instance

```ts
// lib/auth.ts
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  database: {
    url: process.env.DATABASE_URL as string,
  },
  emailAndPassword: {
    enabled: true,
  },
})
```

## 4. Mount the route handler

```ts
// app/api/auth/[...all]/route.ts
import { auth } from "@/lib/auth"
import { toNextJsHandler } from "better-auth/next-js"

export const { GET, POST } = toNextJsHandler(auth)
```

## 5. Generate and apply the schema

```bash
npx better-auth migrate --yes
```

## 6. Create the client

```ts
// lib/auth-client.ts
import { createAuthClient } from "better-auth/client"

export const authClient = createAuthClient()
```

## 7. Sign up and sign in

Call these from any component or route handler:

```ts
import { authClient } from "@/lib/auth-client"

// Sign up a new user
await authClient.signUp.email({
  email: "user@example.com",
  password: "supersecret",
  name: "Alice",
})

// Sign in an existing user
await authClient.signIn.email({
  email: "user@example.com",
  password: "supersecret",
})
```

## 8. Read the session

```ts
import { authClient } from "@/lib/auth-client"

const { data: session } = await authClient.getSession()
console.log(session?.user)
```

Your app now has a working authentication layer. To add a social provider like Google or GitHub, see [Authentication](/docs/authentication). To add two-factor auth, organizations, or API keys, see [Plugins](/docs/plugins).
