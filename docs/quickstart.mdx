# Quickstart

This guide takes you from a fresh install to a working sign-in flow using email and password. By the end you'll have a server-side auth instance, a typed client, and a working sign-up and sign-in call.

## 1. Install and configure

If you haven't installed Better Auth yet, see [Installation](/docs/installation). Once the package is in place and your `lib/auth.ts` exists, make sure `emailAndPassword` is enabled:

```ts
// lib/auth.ts
import { betterAuth } from "better-auth"

export const auth = betterAuth({
  database: {
    url: process.env.DATABASE_URL as string,
  },
  emailAndPassword: {
    enabled: true,
  },
})
```

## 2. Mount the API handler

Mount Better Auth's request handler in your framework. For Next.js App Router:

```ts
// app/api/auth/[...all]/route.ts
import { auth } from "@/lib/auth"
import { toNextJsHandler } from "better-auth/next-js"

export const { GET, POST } = toNextJsHandler(auth)
```

## 3. Create the client

Create a shared auth client that your UI can import. The client infers types directly from your server instance.

```ts
// lib/auth-client.ts
import { createAuthClient } from "better-auth/client"

export const authClient = createAuthClient({
  baseURL: process.env.NEXT_PUBLIC_AUTH_URL,
})
```

## 4. Sign up and sign in

With the client in place, call `signUp.email` to create an account and `signIn.email` to authenticate:

```ts
import { authClient } from "@/lib/auth-client"

// Create a new account
await authClient.signUp.email({
  email: "user@example.com",
  password: "supersecret",
  name: "Jane Doe",
})

// Sign in with existing credentials
const { data, error } = await authClient.signIn.email({
  email: "user@example.com",
  password: "supersecret",
})
```

## 5. Read the session

Once signed in, read the active session from any client component:

```ts
const { data: session } = await authClient.getSession()
console.log(session?.user.email)
```

On the server side, use `auth.api.getSession` and pass the request headers directly:

```ts
import { auth } from "@/lib/auth"
import { headers } from "next/headers"

const session = await auth.api.getSession({
  headers: await headers(),
})
```

## Next steps

You now have a working auth flow. To add social sign-in (Google, GitHub, Discord, and many more), head to [Authentication](/docs/authentication). To layer on features like two-factor auth, organizations, or API keys, see [Plugins](/docs/plugins).
